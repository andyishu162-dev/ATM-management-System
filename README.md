# ATM management System
ATM Management System using Java Swing
🏦 ATM Management System using Java

A desktop-based ATM Management System developed using Java Swing. This project simulates basic ATM operations through a graphical user interface (GUI).

📌 About the Project

The ATM Management System is a beginner-friendly Java project designed to demonstrate  GUI development, event handling, and basic banking operations.

✨ Features

- 🔐 Login System — Account number and PIN validation.
- 💰 Check Balance — View the current account balance.
- 💵 Deposit Money — Deposit money into the account.
- 💳 Withdraw Money — Withdraw money from the account.
- 📜 Mini Statement — View transaction history.
- 🔑 Change PIN — Change the account PIN.
- 🚪 Logout — Safely return to the login screen.
- 🎨 User Interface — Java Swing-based graphical interface.

🛠️ Technologies Used

- Java
- Java Swing (GUI)
- AWT (UI styling)
- ArrayList (transaction history)
- Visual Studio Code

▶️ How to Run the Project

1. Install the Java Development Kit (JDK).
2. Install Visual Studio Code and the Java extensions.
3. Clone or download this repository.
4. Open the project folder in VS Code.
5. Check that the Java package declarations and folder structure match.
6. Run "login.java" using the Java extension, or compile and run the project using the appropriate Java commands for your package structure.

🧪 Sample Login

Use the sample account details configured in the source code to test the application. The default PIN in the current development version is "0123", unless you have changed it.

Note: This is an educational project. It uses in-memory data and is not connected to a real banking system or database. Account balance and transaction history are not permanently saved after the application closes.
